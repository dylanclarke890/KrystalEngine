Source: https://dom.spec.whatwg.org

1.3. Selectors - https://dom.spec.whatwg.org/#selectors
 - scope-match a selectors string - requires CSS selector parsing and matching, which is not yet implemented.
     - https://dom.spec.whatwg.org/#scope-match-a-selectors-string

2.3. Legacy extensions to the Window interface - https://dom.spec.whatwg.org/#interface-window-extensions
 - Window interface - readonly attribute (Event or undefined) event; not implemented, as Window interface is not supported.
     - https://dom.spec.whatwg.org/#dom-window-event

2.5. Constructing events - https://dom.spec.whatwg.org/#constructing-events
 - check this has been implemented fully

2.7. Interface EventTarget - https://dom.spec.whatwg.org/#eventtarget
 - AddEventListener - service workers currently not supported.
     - https://dom.spec.whatwg.org/#add-an-event-listener
 - RemoveEventListener - service workers currently not supported.
     - https://dom.spec.whatwg.org/#remove-an-event-listener
 - Add/RemoveEventListener - We need a way of passing a lambda instead of a EventListenerCallback as it's awkward to use.
   The issue to solve is how to compare the lambda to the callback when adding/removing listeners.

2.8. Observing event listeners - https://dom.spec.whatwg.org/#observing-event-listeners
 - To legacy-obtain service worker fetch event listener callbacks algorithm not implemented, as service workers are not supported.
     - https://dom.spec.whatwg.org/#legacy-obtain-service-worker-fetch-event-listener-callbacks

2.9. Dispatching events - https://dom.spec.whatwg.org/#dispatching-events
 - DispatchToTarget - Let targetOverride be target, if legacy target override flag is not given, and target’s associated Document otherwise. not implemented, as Window interface is not supported.
     - https://dom.spec.whatwg.org/#concept-event-dispatch
 - InnerInvoke - Let global be listener callback’s associated realm’s global object not implemented, as it uses the legacy extension to the Window interface, which is not supported.
 - InnerInvoke - If global is a Window object, then record timing info for event listener given event and listener. not implemented, as Window interface is not supported.
 - InnerInvoke - Call a user object’s operation with listener’s callback, "handleEvent", « event », and event’s currentTarget attribute value. Not supported as this is a JavaScript concept.
 - InnerInvoke - Should have some way of logging exceptions potentially thrown by the user’s operation.
 - InnerInvoke - If global is a Window object, then set global’s current event to currentEvent. Same as above, not implemented, as Window interface is not supported.
     - https://dom.spec.whatwg.org/#concept-event-listener-inner-invoke

3.2. Interface AbortSignal - https://dom.spec.whatwg.org/#abortsignal
 - onabort EventHandler attribute; Haven't figured out how to support EventHandler attributes yet, as this is a JavaScript concept.
     - https://dom.spec.whatwg.org/#dom-abortsignal-onabort
 - Timeout - Task queues and timers are required to implement this.
     - https://dom.spec.whatwg.org/#concept-abortsignal-timeout
 - Let resultSignal be a new object implementing signalInterface using realm. We only have one AbortSignal implementation, so this is not implemented.
     - https://dom.spec.whatwg.org/#create-a-dependent-abort-signal

3.2.1. Garbage collection - https://dom.spec.whatwg.org/#garbage-collection
 - A non-aborted dependent AbortSignal object must not be garbage collected while its source signals is non-empty and it has registered event listeners for its abort event
   or its abort algorithms is non-empty - I don't understand this properly enough to know how to implement it, so this is not implemented.
     - - https://dom.spec.whatwg.org/#garbage-collection

4.2.2.5. Signaling slot change - https://dom.spec.whatwg.org/#signaling-slot-change
 - Signaling slot change - Append slot to slot’s relevant agent’s signal slots. Don't have 'relevant agents' or 'signal slots'
 - Signaling slot change - Queue mutation observer microtask. Don't have microtasks or task queues, so this is not implemented.
     - https://dom.spec.whatwg.org/#signaling-slot-change

 - Move - Custom element reactions are required.
     - https://dom.spec.whatwg.org/#concept-node-move
 - Remove - Custom element reactions are required.
 - Remove - Transient mutation observers are required at the end of this algorithm.
     - https://dom.spec.whatwg.org/#concept-node-remove

 - QuerySelector/QuerySelectorAll - Requires selector parsing and matching.
